Perguntas Frequentes

Preciso ter o instrumento?

O ideal é ter para praticar, mas ajudo você a escolher a melhor opção com o melhor custo-benefício para iniciar.

Qual a idade mínima?

Ensino crianças, adolescentes e adultos. Nunca é tarde para começar a tocar.

As aulas são online?

Sim. Ofereço aulas online para todo o Brasil e presenciais para alunos residentes no Rio de Janeiro.
